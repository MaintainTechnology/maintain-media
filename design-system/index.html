Logo

The ascending “M” mountain mark with the Maintain Media wordmark. Prefer the vector SVGs; the light-background version carries dark text, the dark-background version white.

Dark background
white wordmark · canonical vector
SVG
Light background
dark wordmark · canonical vector
SVG

Do

  • Use the SVG vectors wherever possible.
  • Keep clearspace ≥ the height of the “M” mark.
  • Match the variant to the background.

Don't

  • Recolour the mark off-brand or add effects.
  • Stretch, rotate, or crop the logo.
  • Place the dark wordmark on a dark background.
