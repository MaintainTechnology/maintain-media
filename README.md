# Maintain Media

Brand-asset library and **design system** for Maintain Media.

## Design system — start here

**[`design-system/index.html`](design-system/index.html)** is the single source of truth for
the brand: every logo, colour, typeface, icon, and graphic — shown in full and linked to the
source files in [`media/`](media/). Open it in a browser, or rebuild it after adding assets:

```bash
python design-system/generate.py
```

- **[DESIGN.md](DESIGN.md)** — written visual spec (colours, type, spacing, tokens).
- **[PRODUCT.md](PRODUCT.md)** — brand strategy, voice, and principles.
- **[media/](media/)** — the source assets (logos, backgrounds, complete toolkit).

When building **any** Maintain Media visual — infographic, document, deck, social graphic, or
website feature — reference the design system first.
