# Maintain Media — Brand Assets

Naming: `maintain-media-<role>[-variant].<ext>` — all lowercase, hyphen-separated, no spaces.

## Brand colors
| Color | Hex | Use |
|-------|-----|-----|
| Purple | `#a04dff` | Primary / logo mark |
| Dark | `#08282d` | Text on light backgrounds |
| White | `#ffffff` | Text on dark backgrounds |
