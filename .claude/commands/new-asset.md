description: Add and organize a new media file into the repo per the naming convention
argument-hint: [path-to-file]
---

A new media asset needs to be brought into the repository: `$ARGUMENTS`

Use the **asset-intake** skill to:

1. Inspect the file and identify what it is.
2. Rename it to `maintain-media-<role>[-variant].<ext>` (lowercase, hyphens, no spaces).
3. Move it into `media/logos/`, `media/backgrounds/`, or `media/brand/`.
4. Update `media/README.md`.

Report the before → after path. Do not delete anything without asking.
