# ABN Lead Engine — beginner knowledge guide

Open **`index.html`** in a browser. Share that single file; its fonts, Maintain Media logo, styles, diagrams and JavaScript are embedded. It needs no installation, internet connection or account.

The guide explains the purpose, business-register sources, contractor example, full system architecture, record contents, priorities, human review, operating controls and recorded pilot status in plain English.

Interactive features:

- Six-step example with previous/next controls.
- System map with optional software names.
- Three examples of whether a record can move to GoHighLevel.
- Expandable answers, score explanation and source notes.
- Chapter links and reading progress.
- Print / save PDF layout with all example steps and explanations expanded.

The content was checked against the repository on **14 September 2026**. It distinguishes product design from dated pilot evidence. In particular, release 011 records an ABR validation request queued on 11 September; the reviewed receipts do not establish a completed baseline. This guide is not a live status screen or an approval to operate the product.

The example business is invented. No credentials or actual business contact details are included. No external requests, data collection, analytics or browser storage are used.

Brand sources: `DESIGN.md`, `PRODUCT.md`, `design-system/index.html` and the canonical logo / Albert Sans / Vela Sans assets in `media/`. Product references are listed in the HTML's source notes.

Validation: browser checks at 320, 360, 390, 820 and 1440 pixels; offline assets; all interactions; reduced motion; keyboard focus; JavaScript-disabled reading; print rendering; automated accessibility checks. Temporary review outputs are in the ignored `out/abn-guide-qa/` directory.
