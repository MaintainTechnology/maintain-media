# Fixture propagation build and review

9 September2026. The task audit found that suppression jobs were enqueued and alarmed but had no downstream consumer. Added `ops/propagation.py`, migration023 and `propagation drain --mode fixture`; `crm drain` now prioritises stops before/after ordinary work. No live transport or notification is enabled.

The worker checks current incident/family authority, uses bounded leases and verifies exact configured remote group mappings. It releases all database/global locks before provider lookup/fetch/update. It clears only engine-owned marketing projection fields, preserves the opaque group identity and unrelated CRM fields/tags, and adds the mapping-approved `maintain-media:suppressed` tag. Completion follows an actual fetched/verified update, or confirmed absence without an unresolved dispatched write. Unknown updates reconcile before another write. Uncertain or crashed dispatch remains pending; an approval blocked before any dispatch does not hold propagation forever. The opt-out ledger is never deleted or relaxed.

Root independently found two draft defects: the tag was not the mapping-approved suppressed tag, and the unresolved-query included never-dispatched approvals. Both were corrected and a dispatched/undispatched negative pair was added. Final focused tests: **7 passed in44.26s** (`uv run pytest tests/integration/test_propagation.py -q`). Tests cover endpoint-only stop, owned-field clearing/unrelated-field preservation, uncertainty, wrong-group refusal, concurrent suppression/claims, quarantine and bounded exhaustion. Ruff and mypy passed for worker, CLI, tests and drill helper.
