# Bounded cost-input implementation — 9 September 2026

T050/R34/R38 previously projected actual usage reservations but had no way to supply purchase cash or dated operator rates. Added fixture-only `cost-import EVIDENCE.json` with a closed validated `CostStatement` model, immutable statement identity/window/cohort allocation, encrypted vendor/receipt evidence and exact micro-AUD conversion. Inputs require aware closed period bounds, dated owner approval, source receipt, native gross/tax/currency/FX/date, unit tariff, minimum commitment and a receipt per cash line. No financial action is performed.

The six cash categories are hosting, storage/backups/requests/egress, enrichment purchases, DNCR, Sheets/CRM licences and developer cost. Operator rate requires its own source reference; `time_coverage_complete` defaults false. A fully loaded total is available only when all six cash categories, a rate and explicitly reviewed time coverage are known. Explicit zero amounts require actual supplied evidence; omitted costs remain unknown. Usage reservations and settlements remain separate from purchase cash and are not added to it.

Statements use exact declared start/end instants. The importer returns `operational_summary` for those same instants when a pipeline run exists, avoiding guessed prorating against a moving current-time window. Optional worklist cohort plus fixed-tier statements produce separate cohort/tier allocations; they are not summed into overall cash or repeated for each originating signal. Worked time uses the existing per-actor activity interval union; ambiguous cross-tier activity is not assigned to every tier.

Migration022 retains receipt bodies at most 90 days after import (subject to explicit cost-statement hold), then keeps only the immutable numeric projection/digest and minimal metadata through 24 calendar months after period end. The retention service purges expired numeric records; absence then projects unknown again. No production financial retention policy is inferred from this fixture path.

Validation: **five PostgreSQL tests passed in 14.78s**, covering known/unknown full costs, native-to-AUD conversion, exact period scope, separate cohort allocation, idempotent replay/conflicts, future/unsubstantiated input rejection, incomplete time coverage and both retention stages. Scoped Ruff and mypy passed; CLI help exposes the new command. Full package checks remain root-owned.
