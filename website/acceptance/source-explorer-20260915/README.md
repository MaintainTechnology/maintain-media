The replacement Source records tab automatically opens the accepted ABR or QBCC publication. It has full-publication ABN/name search, source-specific filters, all 14 ABR / 17 QBCC stored fields and complete/filtered CSV actions. Run history opens the exact selected run. Latest leads has independent source filters.

Actual React/browser validation passed 18 interactions at four viewport widths. Rendering and payload validation passed 26 cases; the bridge passed 28 cases. Browser fixtures contain synthetic businesses only. The separate two-origin browser check proves the required strict-origin dashboard header; no-referrer would send a null Origin and fail authenticated downloads. Interrupted/queued-worker and preflight cancellation regressions both passed.

The full accepted ABR CSV was parsed, counted and SHA-256 checked: 20,510,902 rows, 14 fields, 7,198,717,434 bytes. Server-side processing took 345.498 seconds; that does not measure a user's network download. The full QBCC export also matched all 108,019 rows and 17 fields. No multi-gigabyte copy was retained. Complete exports include every matching row regardless of table pagination.
